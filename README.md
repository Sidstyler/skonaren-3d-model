# Skonaren 3 & 4, Hjo – 3D model

Interactive Three.js model of the villa, the new addition (tillbyggnad) and the garage,
built from building-permit drawings (Aaro Arkitektkontor, project 369).
Colours and some details are assumed.

Open `index.html` through a local web server, for example:

    python -m http.server 8765

then visit http://localhost:8765/. Drag to orbit, scroll to zoom.
